About this pilot

Dominus Estate · Napanook Vineyard dispatch prototype V3.0. This is a self-contained demonstration, not deployed field software.

What is simulated

  • Tractor position, heading and trails are scripted along generated row paths. It is not live GPS.
  • The supervisor alert is raised in-page. No message leaves this browser; nothing is sent to a server.
  • Work orders are stored only in this browser (localStorage) and are not shared between devices.
  • The wrong-block alert uses point-in-polygon tests against the Napanook block boundaries. GPS position alone does not prove an implement is working; a production system needs working-state inference, GPS-uncertainty handling, false-positive mitigation and field validation.
  • Satellite imagery loads from Esri World Imagery and needs internet access. Blocks 29, 30N and 30S come from the newer plantings geodatabase.

Production roadmap (not built)

  • Shared secure backend, user identity and roles, persistent ranch / work-order / task records, audit trail.
  • Native iPad app with background GPS, cellular/offline queue and sync, push alerting, GPS logs, privacy and retention policy.
  • Task verification, editing of live work orders, operations catalog, Hopper Ranch and Ulysses Vineyard.
